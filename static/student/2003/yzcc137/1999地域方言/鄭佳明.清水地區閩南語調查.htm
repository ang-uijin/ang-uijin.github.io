清水地區閩南語調查

 

鄭佳明

靜宜大學中文系

關鍵字：清水

1.        前言

由於接觸到語言學這門課的緣故,使我們了解語言在我們日常生活中佔有 多麼重要的地位!每一句話都有其涵意,而且能傳達彼此間的訊息,增進彼此的情 感,這不是能以手勢或其它方式就能說明,就像閩南語的腔調,上完課後才發覺一 個小小的台灣,在語言的腔調上就有多麼的繁雜與不同,更何況在這個世界上,各 國的語言是何其多,再加上各地的方言更是不勝枚舉!所以為了進一步的了解語 言,就要從最根本的地方做起,從我們本身所接觸的環境來了解,由小地方著手,一 點一滴的累積自己的經驗,進而歸納出一個大方向.也唯有透過實地的去做田野 調查,才能了解其語言的變化情形,因而促使了我們在語言學方面踏出了成功的 第一步.

2.        調 查 方 式

本組利用問卷調查配合錄音的方式,來了解清水鎮本地人和外地人,兩種不同的口音混合情形,因為要配合本身調查同學的交通便利而選擇了清水鎮,以約50份的問卷把本地人的口音和外來人口的口音做一個區分,再將本地人和外地人口音變形做一個比較,順便了解清水鎮本地人的口音為何?來做一個問卷調查,以下是調查方式:

記音點:以清水鎮為主,里為調查單位做抽樣調查.

發音人性別:了解男女間發音有為很大差別(在地人).

年齡:分老(60~以上).中(40~60).青(39~20).少(20~以下)以此為年齡分布標準.

祖籍:了解原本的是那一種腔調.

其他語言能力:有華語.客語.英語.日語.了解其語言能力.

父母成長地:了解父母原本方言口音,而了解發音人被父母影響的程度.

遷居經歷:了解發音人是受何種環境影響.

教育程度:了解其知識水準程度.

宗教:了解本地宗教的情形.

職業:了解其發音人所接觸的人是否有影響口音.

發音腔調:以特定幾個語句來了解.判斷發音人是何種口音.

由於為問卷調查的方便,並不留下發音人的電話.姓名及連絡處,但會記錄是那一里和發音時的口音,也可以在里與里之間做一個區別,但老年人接受訪問的意願非常低,所以會以中年人為主,調查的對象是以現在住在清水鎮各里的人為範圍,做抽樣的問卷及錄音記錄,以便做資料整理,以上是本組的調查方向及目的.

4.        結 論 

從以上資料可以了解到,清水本地人被影響的腔調在職業方面從商的比例較高,所以為迎合顧客也可能做些改變,但在大部分都是以本地人的方式來同化外地人,而外地人的改變較多;在年齡分布方面,中年人也比較大概可彌補老年人的資料;在教育程度方面,以高中和大學程度較多,可能在求學過程中進入其它的腔調,因而使的泉州腔變的較多;在宗教方面,以民間宗教為主,並無太大影響;在語言能力方面,以華語為主,其它語言所佔只是很微小的比例.

  綜合以上比較,外地人與本地人的影響主要的原因可歸納出以下幾點:

職業:因從商的關係,所接觸到的人較廣的原故,在不知不覺中改變了本地人原有的口音.

教育程度:因為高中、大學的學生大都是從各地前來就讀的學生,因此各地口音的混合更是加重了本地人改變口音的比例.

祖籍:由於本地人大多來自泉州,因此大都以泉州腔為主.

語言能力:以華語為主,並無其它語言超過40%的比例,因此並無太大影響.

主要被影響改變較多的是外地人,因為在走入本地人的地盤,口音自然會被同化,而本地人也會不自覺的接受某一些外來口音,才會造成今日差距的縮短,而且並不會相差很多.

    以上五點是比較以後的調查結論.
